# Тендер-бот

Telegram-бот, который следит за тендерными площадками и присылает новые тендеры,
подходящие под ключевые слова. Сайты и ключевые слова настраиваются прямо в боте —
код править не нужно.

## Что умеет

- **Админка внутри Telegram** — добавление сайтов, ключевых слов и админов через меню.
- **Автоподбор селекторов** — при добавлении сайта бот сам находит список тендеров
  на странице и показывает превью для подтверждения.
- **Ключевые слова с логикой** — точное слово, префикс (`ремонт*`), фраза целиком,
  минус-слова (`-аварийный`).
- **Без повторов** — каждая позиция уведомляется один раз (дедупликация по ссылке).
- **Без спама при подключении** — при добавлении сайта текущие тендеры помечаются
  просмотренными, приходят только новые.

## Быстрый старт локально

```bash
npm install
cp .env.example .env.local   # заполните значения
npm run bot:local
```

`npm run bot:local` запускает бота через long polling — публичный URL не нужен.
Сайты проверяются каждые `CHECK_INTERVAL_MINUTES` минут (по умолчанию 15).

Переменные окружения:

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `OWNER_TELEGRAM_ID` | [@userinfobot](https://t.me/userinfobot); можно несколько через запятую |
| `DATABASE_URL` | Neon Postgres (см. ниже) |
| `CRON_SECRET` | любая длинная случайная строка: `openssl rand -hex 32` |

## Деплой на Vercel

```bash
npx vercel link          # привязать проект
npx vercel env pull      # позже — забрать переменные локально
```

1. **База данных.** В дашборде проекта → *Storage* → *Marketplace* → **Neon Postgres**.
   После подключения `DATABASE_URL` появится в переменных проекта автоматически.
2. **Остальные переменные.** Добавьте `TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID`,
   `CRON_SECRET` для окружений Production и Preview:

   ```bash
   npx vercel env add TELEGRAM_BOT_TOKEN production
   ```
3. **Деплой.**

   ```bash
   npx vercel --prod
   ```
4. **Инициализация.** Один раз откройте в браузере:

   ```
   https://<ваш-домен>.vercel.app/api/setup?secret=<CRON_SECRET>
   ```

   Это создаст таблицы и подпишет бота на webhook. В ответ придёт `{"ok":true,...}`.

   **Повторяйте этот шаг после каждого деплоя, где в `src/lib/db.ts` появились
   новые таблицы или колонки** (последняя такая — `invites` для приглашений):
   миграция идемпотентна, а без неё меню «👤 Админы» будет отвечать сбоем.
5. Напишите боту `/menu` в Telegram.

## Расписание проверок

`vercel.ts` содержит cron на `/api/cron`. **На Hobby-плане Vercel Cron срабатывает
только раз в сутки** — поэтому в конфиге стоит ежедневный запуск, иначе деплой не пройдёт.

Чтобы проверять чаще, есть два пути:

- **Pro-тариф** — поменяйте в `vercel.ts` расписание на `*/15 * * * *`.
- **Внешний планировщик** (бесплатно, работает и на Hobby) — например
  [cron-job.org](https://cron-job.org): создайте задание с интервалом 15 минут на адрес

  ```
  https://<ваш-домен>.vercel.app/api/cron?secret=<CRON_SECRET>
  ```

Кнопка «▶️ Проверить сейчас» в меню бота запускает обход вручную в любой момент.

## Ключевые слова

| Запись | Что ловит |
|---|---|
| `ремонт` | слово «ремонт» целиком |
| `ремонт*` | «ремонта», «ремонтные», «ремонту» |
| `поставка мебели` | фразу целиком, слово в слово |
| `-аварийный` | минус-слово: отменяет совпадение, даже если сработало другое |

Поиск нечувствителен к регистру, «ё»/«е» и пунктуации. Пустой список ключевых слов
означает «присылать все новые тендеры».

## Ограничения

**Сайты, где список рисуется JavaScript'ом, не парсятся.** Бот скачивает HTML и
разбирает его — если площадка (например, `zakupki.gov.kg` на PrimeFaces) подгружает
таблицу отдельным ajax-запросом, в HTML её нет. Бот это распознаёт и говорит прямо.
Обходные пути:

- указать вместо страницы адрес её JSON/XML-выгрузки, если он у площадки есть;
- использовать «печатную» или облегчённую версию списка;
- для таких площадок нужен headless-браузер (Playwright) — в serverless это
  отдельная история с размером бандла, в текущую версию не входит.

## Архитектура

```
src/
  app/
    api/telegram/route.ts   webhook Telegram (grammY)
    api/cron/route.ts       плановый обход сайтов
    api/setup/route.ts      миграции + подписка на webhook
    page.tsx                служебная страница статуса
  lib/
    db.ts        подключение к Neon + схема
    repo.ts      весь SQL: сайты, слова, админы, дедупликация, состояния
    scrape.ts    загрузка страницы, извлечение по селекторам, автоподбор
    match.ts     нормализация текста и матчинг ключевых слов
    checker.ts   обход сайтов и рассылка
    notify.ts    форматирование сообщений
    bot/         меню, диалоги, обработчики
scripts/dev-bot.ts          локальный запуск через long polling
tests/                      unit-тесты матчинга и парсинга
```

Состояние диалога хранится в таблице `user_state`, а не в памяти процесса:
у serverless-функций нет общей памяти между запросами.
